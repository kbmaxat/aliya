# Алия Жакупова | Психолог и арт-терапевт

Статический сайт-лендинг для психолога и арт-терапевта, опубликован на GitHub Pages:
https://kbmaxat.github.io/aliya/

## Дизайн
- современная редакционная вёрстка: крупная антиква Fraunces + Manrope;
- палитра — тёплый бумажный фон, глубокий зелёный, мягкий шалфейный и терракотовый акцент;
- чередующиеся цветовые блоки, скруглённые карточки, появление секций при прокрутке;
- на стартовом блоке — портрет с удалённым фоном на зелёной форме.

## Содержание
- блоки «Обо мне», «Образование и опыт», «С чем я работаю», «Арт-терапия», «Как проходит встреча», «Услуги», «Организациям»;
- галерея, короткие видео из YouTube, стоимость;
- форма заявки с проверкой от спама и локальным сохранением (без бэкенда);
- страница «Политика обработки данных».

## Структура
- `index.html` — страница;
- `styles.css` — дизайн-система и адаптив;
- `script.js` — меню, анимации появления, подсветка навигации, форма;
- `assets/` — изображения, документы (CV, диплом, коммерческое предложение), favicon;
- `.github/workflows/pages.yml` — деплой на GitHub Pages при пуше в `main`.
