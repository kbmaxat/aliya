# Психолог и арт-терапевт — Алия Жакупова

Сайт-портфолио и landing page для психолога / арт-терапевта с акцентом на индивидуальную работу, групповую поддержку и корпоративные арт-терапевтические программы.

## Что включено
- адаптивный landing page;
- блоки про специалиста, образование, услуги, арт-терапию, процесс встречи;
- форма записи для GitHub Pages;
- коммерческое предложение в PDF;
- политика обработки данных;
- встроенные YouTube Shorts из предоставленных роликов;
- готовая структура под публикацию на GitHub Pages.

## Локальный запуск
1. Откройте папку проекта.
2. Запустите локальный сервер:
   ```bash
   python -m http.server 8000
   ```
3. Откройте в браузере:
   ```text
   http://localhost:8000
   ```

## Как изменить контакты
В файле `index.html` найдите блок `Контакты` и замените текст в секции `contact-list` и в форме.

Если актуальные данные есть в резюме, замените поля:
- WhatsApp
- Email
- Instagram

В текущем проекте данные оставлены в безопасных placeholder, потому что в доступных материалах не было достаточно достоверной контактной информации для корректного заполнения без риска выдумать факты.

## Как настроить форму
Форма заявки использует статический подход для GitHub Pages.

1. Зарегистрируйтесь на Formspree или Web3Forms.
2. Получите endpoint.
3. В `index.html` замените:
   ```html
   action="https://formspree.io/f/your-form-id"
   ```
   на ваш реальный endpoint.

Не публикуйте секретные ключи в публичном репозитории.

## Как обновить PDF
PDF-коммерческое предложение можно пересобрать через Python:

```bash
py scripts/generate_commercial_offer.py
```

Готовый файл будет сохранён в:
```text
./assets/commercial-offer.pdf
```

## Как опубликовать на GitHub Pages
1. Создайте репозиторий на GitHub.
2. Загрузите содержимое проекта в ветку `main`.
3. В настройках репозитория откройте раздел `Pages`.
4. Источник публикации: `Deploy from a branch`.
5. Выберите ветку `main` и папку `/root`.
6. Сохраните.
7. GitHub выдаст публичный URL сайта.

## Примечание по контенту
Некоторые реальные данные (например, точные контакты и часть рабочего опыта) не были доступны в предоставленных материалах. Поэтому в проекте использованы безопасные placeholder и проверенные сведения из дипломов и сертификационных документов. Никакие не подтверждённые данные сознательно не добавлялись.
