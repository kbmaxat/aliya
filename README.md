## Форма заявки
Бэкенда нет. При отправке форма:
1. резервно сохраняет заявку в `localStorage` браузера посетителя;
2. открывает WhatsApp (`+7 776 155 03 28`) с уже собранным текстом заявки.

Чтобы заявки приходили в почту / Google-таблицу / Telegram, нужно подключить
внешний сервис (Formspree, Google Apps Script и т.п.) в `script.js`.

## Структура
- `index.html` — страница;
- `styles.css` — дизайн-система и адаптив;
- `script.js` — меню, анимации появления, подсветка навигации, форма;
- `assets/documents/` — CV, дипломы, сертификаты, коммерческое предложение;
- `assets/images/` — фотографии, портрет с удалённым фоном (`portrait.png`);
- `.github/workflows/pages.yml` — деплой на GitHub Pages при пуше в `main`.
